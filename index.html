PyTask CLI — Case Study

Terminal Productivity & Study Schedule Engine

Background & Motivation

As a 1st-year student balancing programming assignments, coursework readings, and practical coding exercises, switching between browser tabs and complex GUI apps caused friction. I built PyTask CLI to run instantly from my terminal.

Key Technical Features

  • Sub-second Execution: Built with Python 3's native libraries for instant startup with zero heavy dependencies.
  • Persistent JSON Storage: Reads and writes tasks with automatic schema checks to prevent data corruption.
  • Priority Sorting Algorithm: Automatically ranks items by urgency (High, Medium, Low) and deadline dates.
  • ANSI Terminal Aesthetics: Styled with formatted status tables and color indicators for quick visual scanning.

What I Learned

Deepened my understanding of Python command-line argument parsing with argparse, structured JSON data serialization, error handling for file I/O, and writing modular Python functions.

StyleCraft — CSS Architecture Lab

Exploring Modern CSS Without JavaScript Overhead

Background & Motivation

Modern CSS has evolved tremendously. Many developers default to heavyweight JavaScript libraries for simple layouts, modals, and responsive interactions. StyleCraft was created as an experimental sandbox to master raw CSS capabilities.

Key Technical Highlights

  • Fluid Grid Layouts: Dynamic repeat(auto-fit, minmax(...)) grids that adjust smoothly across all screen sizes without media query clutter.
  • CSS Custom Properties Token System: A structured palette of variables for dark mode background elevations, typography scales, and accent glow radii.
  • Hardware-Accelerated Transitions: 60fps animations leveraging transform and opacity with custom cubic-bezier timing.
  • CSS-Only Interactivity: Modals and navigation toggles powered strictly by HTML states (:target and checkbox hacks).

What I Learned

Sharpened my understanding of the CSS box model, stacking contexts (z-index), pseudo-classes, responsive typography with clamp(), and building accessible UI.
